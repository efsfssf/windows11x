# Windows 11X — исследовательский атлас

Сайт проекта WCOS / NT 26100 с общим планом и редактором содержимого.

- **Без входа:** просмотр всех страниц, исследований, отметок и заметок; поиск, чтение и скачивание документов, экспорт.
- **После входа владельца:** общие отметки и заметки, добавление задач, импорт плана, редактор сайта и восстановление полной копии.
- **Редактор:** название и навигация, дата среза и SHA, тексты страниц, карточки обзора, лестница доказательств, исправления, этапы и задачи, события с любыми датами, архитектура, роли томов и фазы, словарь, метаданные и содержимое исследований. Записи можно добавлять, удалять и переставлять.

## Комментарии к задачам

Вместо одной заметки у задачи — список комментариев. Откройте задачу, укажите **дату исследования**, введите результат и нажмите **Добавить комментарий**. Можно добавить несколько записей, изменить текст или дату и удалить отдельный комментарий. Время добавления показывается отдельно от даты исследования. Без входа доступны только чтение и экспорт.

Прежние заметки автоматически становятся комментариями с пометкой **Дата исследования не указана**: дата не придумывается. Владелец может указать её при редактировании. Перенос сохраняется на сервере вместе со следующим изменением плана. Старые экспорты по-прежнему импортируются, а новые копии и сводка для ИИ включают комментарии и их даты.

Изменения сохраняются **на сервере** и видны другим посетителям после обновления страницы. База данных и сборка JavaScript не нужны. Открытие `index.html` без PHP даёт только просмотр исходного среза; для актуальных общих данных открывайте адрес сайта.

## Первое включение на хостинге

Нужен PHP **8.1+** с обычными расширениями `json` и `session`, HTTPS и доступ PHP на запись в закрытую папку **вне корня сайта**. Открытой регистрации и пароля по умолчанию нет: до настройки всем доступен только просмотр.

1. Опубликуйте файлы. Существующий GitHub Actions workflow проверяет код и загружает сайт по FTP при push в `main` в `/domains/dandomi.tech/public_html/`.
2. В терминале хостинга выполните:

   ```bash
   cd /domains/dandomi.tech/public_html
   php scripts/configure-admin.php
   ```

   Введите логин и дважды пароль длиной от 12 символов. Скрипт сохраняет только хеш пароля в `/domains/dandomi.tech/windows11x-private/config.php`. Если хостинг использует другой путь, сначала перейдите в фактическую папку сайта.
3. Откройте сайт → **Войти** → **Редактировать**. Содержимое редактора применяется кнопкой **Сохранить на сервере**; отметки и заметки сохраняются автоматически, результат виден в строке состояния.

Если терминала на хостинге нет: запустите `php scripts/configure-admin.php` на компьютере с PHP и загрузите созданную папку `windows11x-private` рядом с `public_html` через файловый менеджер/FTP. Не помещайте её внутрь `public_html`. PHP на хостинге должен иметь право читать конфигурацию и создавать файлы в этой папке (владелец — пользователь PHP; обычно папка `0700`, конфигурация `0600`).

Повторный запуск скрипта меняет пароль и делает прежние сессии недействительными. Время входа — 8 часов. Пароли не передавайте в чат и не коммитьте.

Другие варианты настройки — переменные окружения PHP:

| Переменная | Назначение |
| --- | --- |
| `ATLAS_PRIVATE_DIR` | Абсолютная закрытая папка данных вне корня сайта. По умолчанию `../windows11x-private` относительно корня сайта. |
| `ATLAS_ADMIN_USER` | Логин, по умолчанию `admin`. |
| `ATLAS_ADMIN_PASSWORD_HASH` | Результат PHP `password_hash()`, имеет приоритет над `config.php`. |

При ограничении `open_basedir` разрешите PHP доступ к закрытой папке через настройки хостинга. Пароль и данные не следует переносить в публичный каталог для обхода ограничения. Для крупных архивов рекомендуется `post_max_size=16M` и `memory_limit=128M` или больше; API принимает до 12 МиБ JSON.

## Существующие данные

Исходные 86 документов и первоначальный план остаются стартовым срезом. После первого сохранения серверная версия имеет приоритет над `content-defaults.js` и `research-data.js`. Следующее FTP-обновление её не затирает: изменяемые файлы находятся вне `public_html`.

Старые отметки из браузера **не публикуются автоматически**. Откройте сайт в прежнем браузере, войдите и нажмите **Перенести старый локальный план**, либо используйте старый **Экспорт JSON** → **Импорт**. Локальная копия остаётся нетронутой. При редактировании содержимого свои шаги переходят в обычные редактируемые задачи с сохранением ID, отметок и заметок.

## Резервные копии и конфликты

**Скачать полную копию** выгружает всё содержимое и общий план. Владелец может вернуть её через **Восстановить копию**. Старый экспорт плана также поддерживается и меняет только отметки, заметки и свои шаги.

В закрытой папке сохраняются `atlas.json` и предыдущая версия `atlas.previous.json`. Перед важными изменениями скачивайте полную копию; для долгой истории настройте резервное копирование закрытой папки на хостинге.

Две вкладки не могут незаметно перезаписать друг друга. При конфликте сохранение блокируется: скачайте полную копию своих изменений, нажмите **Загрузить актуальные данные** и повторите нужные правки. При ошибке сети можно повторить сохранение. Не закрывайте вкладку до сообщения **Сохранено на сервере**.

Все данные атласа, включая заметки, публичны по задаче проекта. Пароль защищает изменение. Проверка прав выполняется на сервере для каждой записи, а не только скрывает кнопки. Используются PHP-сессии, CSRF-токен, ограничение попыток входа, проверка структуры данных, атомарная запись и проверка ревизии.

## Файлы и проверки

- `index.html`, `styles.css`, `app.js` — интерфейс и отображение.
- `editor.js` — вход, редактор и синхронизация с сервером.
- `comments.js` — обсуждения задач и перенос прежних заметок.
- `content-defaults.js` — стартовые настройки, тексты и структуры.
- `research-data.js`, `library/` — стартовые документы. Скачивание из читателя отражает текущий, в том числе отредактированный, текст.
- `api/index.php` — чтение, авторизация и запись.
- `scripts/configure-admin.php` — настройка владельца, работает только из CLI.

```bash
node --check app.js
node --check editor.js
node scripts/smoke-ui.js
php -l api/index.php
php -l scripts/configure-admin.php
python3 scripts/test-api.py
```

Проверка API запускает отдельный PHP-сервер со случайным паролем и временной папкой: гостевой доступ, запрет записи без входа, CSRF, вход/выход, сохранение всех 86 источников, чтение другим клиентом, новые этапы/даты/документы, конфликт ревизий, валидация, резервная версия и ограничение попыток входа. Рабочие данные сайта она не затрагивает. При необходимости задайте `PHP_BIN` с путём к PHP CLI.
