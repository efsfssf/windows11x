# Windows 11X — исследовательский атлас

Локальный сайт для проекта настоящей WCOS на NT 26100. Откройте [index.html](index.html) двойным щелчком или запустите `ОТКРЫТЬ-САЙТ.cmd`. Интернет, сборка проекта и сервер не нужны.

## Что есть на сайте

- **Обзор:** текущая точка, последняя dual V6+V7 схема и лестница доказательств.
- **Большой план:** этапы G0–G7, отметка/снятие отметки каждого шага, свои шаги и заметки. Число галочек означает только состояние списка, а не готовность ОС.
- **Как устроено:** сравнение работающей Factory OS 22000 и исследуемой 26100, роли томов и фаз.
- **Хронология:** исследования 5–12 ноября и график количества документов по датам.
- **Исследования:** 86 доступных текстовых документов, включая все 28 текстовых/JSON материалов из `JSON_Results_From_AI.rar`, технические отчёты, лабораторный пакет новой схемы и актуальный handoff. Поиск работает и по содержимому.
- **Словарь:** короткие объяснения и исправления прежних неверных выводов.

Галочки и заметки автоматически сохраняются в хранилище браузера на этом компьютере. В разделе плана есть **Скопировать для ИИ** — текстовая сводка для вставки в чат, а также **Экспорт JSON** и **Импорт** для переноса в другой браузер или резервной копии. JSON включает названия задач и критерии, поэтому он понятен и без этого сайта. Если открыть сайт в другом профиле браузера, импортируйте сохранённый JSON.

## На чём основан текущий статус

Срез знаний — **12 ноября 2026**. Точный DLL из приложенного `Windows11X-APISet-26100-V6V7-OFFLINE-LAB.zip` независимо прочитан из архива: SHA-256 `75FB8F895EA030C60F435863971EEB025798ABDC306958B593DBE6EB185C0BBD`. Он прошёл офлайн-проверку V6/V7, но имеет `Authenticode: HashMismatch`, не установлен и не проверен при boot.

Поздние исправления от 9–11 ноября имеют приоритет над ранними гипотезами. Особенно: `SEALED` ограничивает overlay; V6-only TraceSmoke не равен dual V6+V7; Phase2 условен; `4/26 SAME` — только ограниченный scope, остальные `22/26 INCONCLUSIVE`; postboot `20/20` не заменяет Core `0/7`.

## Файлы

- `index.html`, `styles.css`, `app.js`, `research-data.js`, `favicon.svg` — сайт.
- `library/` — текстовые копии источников, открываемые и скачиваемые из сайта.
- `scripts/build_research.py` — сборка каталога из локальной папки `.research/`.
- `scripts/smoke-ui.js` — проверка всех шести экранов и целостности каталога без браузера.
- Три исходных архива в корне папки не менялись и не используются сайтом как исполняемые файлы.

Для публикации достаточно файлов сайта и папки `library/`. В первичных текстах встречаются локальные пути и пользовательские журналы; просмотрите их перед открытой публикацией. План и заметки из вашего браузера в файлы сайта автоматически не попадают.

Проверка логики: `node scripts/smoke-ui.js`.
