# Исправления предыдущих утверждений

1. `HashFactor` стандартного v6 header — dword `+0x18=31`; `+0x1C=0xFF080007` в 26100 начинается с embedded marker `7`. Приписывать `7` hash multiplier неверно.
2. `Namespace.Flags` оригинала 26100 по `+0x08` равно `0`. `Flags=1` относится к **State Separation entry**, не ко всей схеме. Trace entry имеет `Flags=0`.
3. `API_SET_SCHEMA_FLAGS_HOST_EXTENSION=2` нельзя переносить в `VALUE_ENTRY.Flags=2` как «исправление». Поля имеют разные уровни; код и тесты не подтвердили такой приём.
4. Фраза «V7 композиция всегда выбрасывает все SEALED host edits» не доказана. Здесь код доказывает выбор embedded 7 и наличие sealed gate при extension; конкретный PhaseBinding runtime переход не снят в одном boot.
5. В PhaseBinding обнаружение строки в памяти и последующий пустой resolver output относятся к **разным загрузкам**. Они не показывают момент удаления строки.
6. B отличается от оригинала не только Unicode-строкой: изменены PE checksum, `.apiset.VirtualSize`, wrapper Size, embedded Size и legacy Trace HostOffset/Length. A и B различаются двумя байтами по file `0x130` и `0x2020`, а не двумя 32-битными полями данных.
7. Живой `schema+0x1F304` при `HostLength=0` не является строкой, даже если `du` отображает случайные символы. Это начало бинарных данных; `UNICODE_STRING.Length` определяет допустимую длину.
8. `0x29C74 = 0x29C60 + 0x14` и `0x29C84 - 0x29C74 = 0x10` — числовые факты. Статический V7 size path теперь показывает способ получить первую сумму; это всё ещё не запись об исполнении конкретной ветки в VM.
9. Сообщение `STAGED` и loader warning подтверждают выбор пути и предварительную проверку исходного B; они не равны SHA-256 установленной гостевой копии. Debugger admission также не доказывает обычное доверие образу.
10. Нельзя использовать FOS 22000 как полностью совместимый 26100 base: 945 против 984 контрактов и другая структура; прежний crash был до host test. У FOS State Separation HostLength `0x1E`, не `0x18`.
11. STrace относится к unsealed Trace и не демонстрирует overlay SEALED State Separation.
12. `eax=0`, resolved marker 1 и `UNICODE_STRING.Length=0` означают обработанный API Set запрос с **пустым** Host. Они не доказывают загрузку драйвера, импорт binding, доверие, ABI или запуск Windows.
13. Отчёты о 974 контрактах относятся к другим ревизиям 26100. Приложенная оригинальная 26100.9278 и варианты A/B содержат 984 entry; считать чужой revision эталоном для этих байтов нельзя.
